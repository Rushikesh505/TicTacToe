# TicTacToe
A simple 2-player Tic Tac Toe game in Java played through the console. Players take turns marking X and O on a 3×3 grid until one wins or the game ends in a draw.

## Features
- Two players take turns using X and O
- Detects win or draw
- Lets you play again after each round
- Easy to run in any terminal or IDE

## Requirements
- Java 8 or higher
- Terminal or Command Prompt
- (Optional) Any Java IDE like IntelliJ, Eclipse, or VS Code

## How to Run
1. Open a terminal in the folder where `TicTacToe.java` is saved
2. Compile the code:
   ```bash
   
   javac TicTacToe.java
